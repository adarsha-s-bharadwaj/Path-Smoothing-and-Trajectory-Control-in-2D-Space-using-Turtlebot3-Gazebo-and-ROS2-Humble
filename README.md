# Path-Smoothing-and-Trajectory-Control-in-2D-Space-using-Turtlebot3-Gazebo-and-ROS2-Humble
This project implements a trajectory planning and control for a differential drive robot using ROS2.   The system takes a set of waypoints, generates a smooth path, converts it into a time-parameterized trajectory, visualizes it in RViz, and controls a TurtleBot3 robot in Gazebo to follow the trajectory.
